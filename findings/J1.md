# J1：Route 3 北端到 captainreturns

## 结论

PASS。J1 已从冻结的 GB6 终点 spyder_route3@4,6 续录到
spyder_mansion@1,13，并设置 v.captainreturns=1。提交的是独立的
12,162 帧 input-mask 段和父段身份/检查点元数据，不含 terminal snapshot；
验收器同时支持从 snapshot 单独续放，以及把 GB6 和 J1 masks 在内存拼接后从
frame 0 重放。

没有手改导入产物，也没有遇到需要新增 importer、RPG Kit 或 PocketJS 能力的
阻塞。Mansion 西半区在救人前按原作被 drinking buddies 封住，因此去程使用
东侧楼梯，找到 Captain Flick 后从西侧楼梯返回；这条最短路线不依赖
Mansion Top。

## 路线与原作语义

1. 从 Route 3 北端返回 Wayfarer Inn，在 9,6 面向 guestbook，选择 Yes。
   原作传送到 Nimrod Room 播放 Enforcer flashback，返回后得到
   enforcers_response=done。
2. 穿过 Wayfarer 上层，从北门回 Route 3，再由西边界进入 Route 4。
3. 使用 Route 4 免费护士回血，沿路击败三名训练师和 Billie；从西口进入
   Flower City，再从北口进入 Route A。
4. 使用 Route A 免费护士回血，击败 Koan、Dagger、Billie 和 Rosy，进入
   Mansion。
5. 使用 Mansion 免费护士回血，击败 Lucy 后走东侧楼梯进入地下室，与
   Captain Flick 对话得到 foundcaptain；击败 Catholi，走西侧楼梯返回，
   触发 captainreturns，并确认临时 NPC 已不再阻挡、控制锁已释放。

没有购物，也没有额外刷级；战斗和对话全由输入按键驱动，没有直接注入胜利
或剧情状态。唯一剧情选择是 guestbook 的 Yes。继承的 Arthrobolt 从 L32
自然升到 L40；终态全队为 Arthrobolt L40 201/201、Aardorn L4 79/79、
Cardiling L8 58/58、Cataspike L3 70/70、Eyenemy L5 83/83、
Pawsand L22 241/241。
