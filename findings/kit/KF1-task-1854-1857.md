# KF1 — current-map actor rendering and pyscroll-compatible occlusion

## Result

The renderer mounts one persistent actor subtree with enough stable image slots
for every map. Page changes and transfers rebind those slots without replacing
native nodes; the position batch is recompiled against only the current map's
slots on transfer. This fixes the 16-to-32-pixel page-swap/origin failure for
NPCs and sprite-backed static objects without changing reducer state.

Player and NPC nodes now share one paint plane and use a lexicographic `(y, x)`
depth. The upper map is clipped into viewport-resident 16-pixel rows whose
depth falls strictly between actors with foot positions at row `y + 1` and
`y + 2`. That is equivalent to pyscroll's `tall_sprites=2` rule: only the upper
cell intersected by the bottom two sprite pixels is repainted above an actor;
upper art in the head cell remains behind the actor. Each upper pixel is still
drawn once, so translucent art does not accumulate alpha.

## Implementation

- `GameView` builds `mapsById` and `slotsByMap` once. Its frame path reads the
  indexed map and iterates only `CurrentMapActors` for the active map.
- `CurrentMapActors` owns stable native image slots and a player depth signal.
  The image nodes survive page, height, and map changes. A transfer rebinds the
  slots and compiles one camera/player/current-NPC `JumpBatch`; ordinary walking
  commits that one batch and does not carry inactive-map slots in it.
- `actorDepth(px, py, worldWidth)` encodes `(floor(y), floor(x))` in one numeric
  z-index. `upperRowDepth(tileY, worldWidth)` places a row between actor pixel
  rows `tileY * 16 + 1` and `tileY * 16 + 2`.
- `OccludingUpperLayer` keeps a viewport-sized modulo ring of row and image-slice
  nodes mounted. Animated-tile nodes use a retained detached pool. On the
  960x544 fixture it mounts 35 rows and 70 chunk slices. Row work returns
  immediately while the tile/chunk windows are unchanged.
- Streamed upper chunks keep one `loadTileTexture` handle per resident chunk;
  every row slice referencing that chunk shares the handle. Existing residency,
  upload-budget, scrolling, and map-switch tests remain unchanged.

## Regression coverage

- A parallel page change turns `late-npc` from an empty 16-pixel page into a
  32-pixel walker while retaining the same node id and exact grid position.
- A map transfer verifies that only one actor container is mounted, the initial
  actor ids remain among the 20 destination slots, and the rebuilt position
  batch writes the expected destination coordinates.
- Thirteen representative occlusion cells are compared pixel-for-pixel against
  the two-pixel-foot model. A north/south overlap also proves that the southern
  actor paints over the northern actor.
- A separate depth test checks `(y, x)` order at all 13 cells and all 16
  sub-tile movement offsets against the bottom-two-pixel rule.
- The same two-second render/state sample is byte-identical at 60, 30, 20, and
  4 Hz after normalising only the host-frame counter.

### 节点生命周期与像素回归

- 上层行和图片切片改为视口大小的 modulo 环，滚动和切图期间始终挂载；切图
  只重绑图片源。需要摘下复用的动画节点在 `detachNode` 前调用正式
  `retain`，取出时 `release`，组件最终清理时释放池内所有引用。
- 新增 400 帧向下、400 帧返回 Paper Town 的像素回归；第一行上层仍在。
  新增跨图复用后的像素回归，以及所有 native 操作都不得命中已销毁 id 的
  追踪断言。
- 真实 G6 journey 共 1,684 帧：原生层销毁过 101 个 id，但之后命中这些 id
  的操作为 0；独立的 400+400 帧滚动复现同样为 0。
- 14 个真实截图（原审查 13 个位置，加花店店员南北重叠）与 pyscroll
  `tall_sprites=2` 参考逐像素一致：每张 48x64 角色窗口和整个 480x272
  视口的差异都是 0。对照图已逐组肉眼检查。journey frame 900 的屋顶、
  招牌和便利店上层行完整；遮掉角色框后的 1,684 个帧哈希与复审中
  “KF1 + retain”结果逐字节一致（SHA-256
  `65e56ffe405a057be8cc467c4bda4dcfdc39a767e536fed03d63ee0d5743eff7`）。

### 走路与切图预算

- 相机、玩家和当前地图 NPC 共用一个预编译位置批处理；稳定走路帧实测只有
  `setPropBatch[18 records] x1`。批处理不再包含隔离的 500-NPC 压力地图槽位。
- 深度签名只在脚底跨过 16 px 上层行边界或演员相对顺序改变时变化；普通
  单像素移动不写 `zIndex`。
- Sunstone village -> forest 的切图帧为 33 个 counted ops：一个
  `setPropBatch[12 records]`、23 次 `setImage`、5 次 `zIndex` 和 4 次
  高度几何写入；`createNode + destroyNode == 0`，且
  `insertBefore + removeChild == 0`。
- 23 次换源的上限来自 14 条目标可见上层行 × 1 个区块列，加 1 个 ground
  源和 8 个持久演员图片源。测试保留走路帧“一次批处理”的原预算，只按该
  推导放宽切图 `setImage`。
- `dist/sunstone.js` 为 344,994 B，原有 `< 345000` 断言未修改。
