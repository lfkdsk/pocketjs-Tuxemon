## Provenance

Each texture is emitted pixel-by-pixel by the deterministic `writeWeatherTexture`
calls in `gen-assets.ts`, which runs as part of `bun run import`:

- `raindrop.png` (2×16): a vertical gradient streak with a rounded alpha ramp.
- `snowflake.png` (4×4): a bright center with softer edge pixels.
- `wind-streak.png` (16×2): a horizontal gradient streak.
- `fog-veil.png` (64×64): a soft radial gradient.

The generator code is part of this repository and is covered by the same
GPL-3.0-or-later license as the rest of the code (see `LICENSE` and the
`license` field in `package.json`); the generated PNGs are therefore
distributed under GPL-3.0-or-later as well. Regenerating them requires no
external assets.
