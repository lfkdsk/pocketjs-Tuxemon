# Audio attributions

The music and sound effects in `assets/audio/` are imported from the
[Tuxemon](https://github.com/Tuxemon/Tuxemon) project (pinned commit
`9e6258ff`) and redistributed under their original licenses. The complete,
verbatim per-asset credits are in [TUXEMON-ATTRIBUTIONS.md](TUXEMON-ATTRIBUTIONS.md)
(Music and Sounds sections); the summary below covers only the files this
repository ships.

The imported files are transcoded (music: QOA, 22.05 kHz mono; SFX: s16 PCM
WAV, 22.05 kHz mono) but the audio content is otherwise unchanged.

- The Tuxemon sounds tree also bundles Kelvin Shadewing's Soundpacks
  (Vol. 1–3, CC BY 3.0). The original pack readme is carried unchanged at

  redistribution condition.
- CC-BY-SA assets are distributed as separate files; this is mere
  aggregation with the GPL-3.0 code and creates no license incompatibility.
- Tuxemon's former CC-BY-NC-SA Newgrounds tracks are not imported.
